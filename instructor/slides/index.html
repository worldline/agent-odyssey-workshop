COURSE · OPEN THE HOOD

What is a Large Language Model?

  • A large neural model trained to predict the next token.
  • Training learns parameters.
  • Chat uses them—it does not retrain the model.

COURSE · OPEN THE HOOD

Training at scale

Pre-training learns parameters from large text and code corpora by predicting the next token. GPUs make these updates scalable.

Tokenization and embeddings

Tokenization yields vocabulary IDs. The learned embedding matrix turns each ID into a vector.

The same token ID selects the same initial vector. Model layers contextualize the full sequence.

Your payment system — technical blueprint
