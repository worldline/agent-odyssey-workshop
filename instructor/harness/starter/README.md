# Harness mission — initial kit

Copy this folder to a new project directory and open the current GitHub Copilot CLI there. You need an active licence only if following the demonstration; watching does not require setup.

Inputs: a short functional brief, OpenAPI YAML, synthetic fixtures and visual assets. No application implementation is supplied here. Read PROMPTS.md and request a plan before execution. Node.js 22+ is needed to run the resulting service.

North Star Supply is the fictional shop aboard Odyssey. Space is narrative, not logistics or extra business rules. No real payments, database, authentication or backend model calls. Never put API keys in the app, prompts or frontend. The service is a stateless unauthenticated educational demo, not a production security design.

Use the current CLI at https://github.com/github/copilot-cli — not the retired gh copilot extension. Keep approvals and verify generated output. Do not start a public tunnel during the build exercise.
